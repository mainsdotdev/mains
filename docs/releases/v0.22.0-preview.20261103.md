**OpenCode joins Mains.**

The first 0.22 preview adds OpenCode as a coding agent, brings Code chats together under their projects, and makes the Tasks screen easier to navigate and filter.

## Work with OpenCode

- **Another agent for Code.** Choose OpenCode alongside Claude, Codex, Copilot, and Cursor. This initial integration is available in Code mode.
- **Use your OpenCode setup.** OpenCode 2.0 or later must be installed on the computer running the agents. Connect a model provider with `opencode auth login`, then review the account and CLI details in Settings → OpenCode.
- **Choose how it works.** Select a model, choose the Build or Plan agent, and answer tool approval requests from Mains.

## Find your Code chats

- **Chats under their project.** Local and worktree conversations share a project list, with branch and worktree context beside each chat.
- **Search across the work.** Find chats by their title, goal, project, workspace, folder, or branch.
- **Keep device context.** Chats from Bridge retain their originating device and share the matching local project when available.

## A clearer Tasks screen

- **Choose your scope.** Browse issues and pull requests through a sidebar organized around your connected services and their resources.
- **Narrow the list.** Filter issues by status, priority, assignee, label, provider, or repository where available.
- **Make statuses consistent.** Map a connected service's issue states to Mains statuses.

## Smaller things

- Approval dialogs present file changes, commands, searches, and MCP inputs more clearly.
- Workspace activity rows make file changes, reviews, and pull requests easier to read and open.
- Remove a mention directly from its chip in the composer.
- Model and effort controls have clearer presentation.
- Codex account details include workspace names and Google Cloud credentials.
- Atlas page history has refined retention for local and synced pages, preserving current revisions and unresolved conflicts.
- Scrolling, layout, and sidebar navigation have further refinements.

## About this preview

This is a pre-release for testing before Mains 0.22.0. It stays outside the stable automatic-update channel.

The release packages target macOS Apple Silicon, macOS Intel, and the standalone server. Mobile builds are distributed separately.

Preview builds use the same Bridge service as stable releases. If you sign in to Bridge, changes sync normally; use a separate application profile for isolated testing.
