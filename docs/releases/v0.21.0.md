# Mains 0.21.0

Mains 0.21 improves document previews, provider discovery, and the handoff between your desktop and phone.

## Desktop and server

- Open DOCX files in the document preview panel with improved formatting and document rendering.
- Follow file mentions and document links from chat, with navigation that opens the relevant file or preview.
- Choose which conversation outputs appear in the Atlas library when working in Code mode.
- Reuse the provider discovery cache and refresh it when account or provider settings change.
- Answer MCP forms with consistent validation, defaults, and supported choice fields across clients.
- Keep sidebar chat navigation reliable while switching between conversation modes.

## Mobile companion

The companion source updates included with this release add:

- Steering for running turns, Codex questions, and suggested follow-up prompts.
- Clearer output cards and links for files the phone can open, with improved document previews.
- More reliable connection recovery, transcript scrolling, output downloads, and cache cleanup after deleting a conversation.
- Read-only handling for Bridge conversations running on another computer.
- Android platform, appearance, and native sheet improvements.

Mobile builds are distributed separately from the desktop and standalone server release assets.

## Operations

- Backup failures preserve bounded Cloudflare error codes without logging credentials, SQL contents, or signed download links.

## Downloads

The GitHub release provides macOS builds for Apple Silicon and Intel, plus the standalone Mains Server archive.
